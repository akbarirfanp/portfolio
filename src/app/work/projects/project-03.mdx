## Overview

Developed a web-based information system using Nuxt (Vue.js + TypeScript) for the frontend and Laravel 12 (PHP) for the backend. The application was designed with a scalable architecture, secure authentication, and integrated online payment processing through Midtrans. System design and planning were documented using UML diagrams to ensure a well-structured development process.
## Key Features

- **Inventory Management**: Developed a web-based inventory management system to manage products, stock levels, and inventory data efficiently.
- **Backend API Development**: Built RESTful APIs using **ASP.NET Core and C#** to handle business logic, inventory operations, and data processing.
- **CRUD Operations**: Implemented Create, Read, Update, and Delete operations for managing inventory and related entities.
- **Database Management**: Designed and managed a relational database to store and retrieve inventory data efficiently.
- **Object-Oriented Programming**: Applied C# and Object-Oriented Programming principles to develop maintainable and structured application components.
- **Version Control**: Utilized Git and GitHub for version control and maintaining a structured development workflow.

## Technologies Used

- **C#**: Primary programming language for backend development.
- **ASP.NET Core**: Framework for building RESTful APIs and backend services.
- **Frontend**: Currently focus on API first and learn .NET
- **PostgreSQL**: Relational database for storing inventory and application data.
- **Entity Framework Core**: ORM for database access and data management.
- **Git & GitHub**: Version control and source code management.
